Malaysia Vehicle Registration Dashboard
Interactive R Shiny Dashboard

Project Overview:
Developed a fully interactive dashboard to visualize Malaysia’s vehicle registration data sourced from data.gov.my. 

The dashboard provides dynamic insights into vehicle trends by make, model, fuel type, and monthly/yearly changes. Unlike static media reports, this tool allows real-time exploration and filtering of large-scale datasets.

The dashboard can be accessed via the following link:

https://gurazuru.github.io/malaysia-car-dashboard
